# UDP-Client & Server C++ 

A client/server Windows application written in C++ using classic Visual Studio. The client application manages display using the "Simple and Fast Multimedia Library", which is for bitmap object display. The car position data is received and decoded using UDP protocol. TCP protocol is used for management control and inter-user text messaging. A Windows service style process runs to support multiple clients. The service runs to pass car data in binary format between clients.
